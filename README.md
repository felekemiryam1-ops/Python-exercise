# Password Generator

## Description

This project is a Python password generator. It asks the user for the desired password length and whether to include uppercase letters, digits, and symbols. The program then generates a random password based on the user's choices.

## Features

* Generates random passwords.
* Allows the user to choose the password length.
* Allows the user to include uppercase letters.
* Allows the user to include digits.
* Allows the user to include symbols.
* Validates that the password length is at least 8 characters.
* Displays the generated password.

## How to Run

1. Open a terminal.
2. Navigate to the project folder.
3. Run the following command:

```bash
python password_generator.py
```

4. Answer the prompts.
5. The program will generate and display a random password.

## Example

```text
How long? 10
Uppercase? y
Digits? y
Symbols? n

Generated Password:
```
